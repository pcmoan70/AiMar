Søknad om samlokalisering - akvakultur
Kvarøy Fiskeoppdrett AS («KF») og Seafood Security AS («SSAS») soker med dette om
samlokalisering av nærmere angitte tillatelser iht til tabell nedenfor.
Tillatelser som søkes samlokalisert
Lokalitet hvor samlokalisering søkes
NL 0070 (900£), NL 0003 (796t)
11112 Kjerkv ik
NL 0070 (900t), NL 0005 (796t)
18717 Hammarvika
NL 0070 (900t), NL 0006 (796t)
45037 Kjolvika1
Samlokalisering innebærer utvidelse av klarert biomasse på Lokalitetene. Søknad om
endring av driftsplan etter akvakulturdriftsforskriften 8 40 handteres av KF og SSAS
direkte overnfor Fiskeridirektoratets regionskontor.
Denne meldingen er signert av både KF og SSAS, og ved sine signaturer på denne
søknaen bekrefter selskapebe at de angitte tillatelser kan samlokaliseres på
Lokalitetene.
Seafood Security AS plikter a overholde de vilkår som blir satt av Fiskeridirektoratet
som driver av konsesjonene.
Pålegg/krav om rapportering fra myndighetene knyttet til virksomheten ved anlegget er
Seafood Security AS sitt ansvar.
Eiendomsretten til overnevnte lokalitet Kjerkvika, Hammarvika og Kjølvika følger
konsesjoner liggende hos Seafood Security AS
